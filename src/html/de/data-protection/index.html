3. Von uns erhobene Daten und Zweck der Verarbeitung

a) Zugriffsdaten (Server-Logfiles)

Bei jedem Zugriff auf unsere Website übermittelt Ihr Browser automatisch Daten an unseren Server. Dazu gehören:

  • IP-Adresse
  • Browsertyp und -version
  • Betriebssystem
  • Referrer-URL
  • Datum und Uhrzeit der Anfrage

Diese Daten werden unbefristet gespeichert, sofern kein Löschantrag gestellt wird.

b) Google Analytics

Wir nutzen Google Analytics, um das Nutzerverhalten auf unserer Website zu analysieren. Sie können die Datenerfassung verhindern, indem Sie das Browser-Add-on zur Deaktivierung von Google Analytics installieren.

c) Google Maps

Zur Darstellung von Karten ist Google Maps eingebunden. Dabei kann Ihre IP-Adresse an Google übermittelt werden. Weitere Einzelheiten finden Sie in der Datenschutzerklärung von Google.

d) Google Fonts

Wir verwenden Google Fonts, um ein einheitliches Erscheinungsbild sicherzustellen. Ihr Browser ruft die Schriftarten dabei gegebenenfalls von den Servern von Google ab.

e) jQuery

Wir nutzen das jQuery-Framework über das CDN von Google, wobei Ihre IP-Adresse übermittelt werden kann.

f) Kontaktformular

Wenn Sie unser Kontaktformular nutzen, erheben wir:

  • Name (freiwillig)
  • E-Mail-Adresse (Pflichtangabe)

Diese Daten werden unbefristet gespeichert, sofern Sie nicht deren Löschung verlangen.

g) Newsletter-Anmeldung

Wenn Sie unseren Newsletter abonnieren, erheben wir Ihre E-Mail-Adresse. Sie können sich jederzeit abmelden.

4. Cookies

Unsere Website verwendet Cookies für Funktionalität und Analyse. Sie können Cookies in den Einstellungen Ihres Browsers verwalten.
